# Content licensing

This repository applies two distinct licences depending on the nature of the
material.

## Source code — AGPL-3.0

All code (notebooks, scripts, functions) is released under the **GNU Affero
General Public License v3.0**. The full text is in `LICENSE`.

In practice: anyone who redistributes this code, or who uses it to provide a
service accessible over a network, must publish their own source code under
the same licence.

This is consistent with CLIMADA, on which the project depends, itself released
under GPL-3.0 by ETH Zurich.

## Editorial content — CC BY-SA 4.0

Analysis text, maps, figures and publications arising from this project are
released under **Creative Commons Attribution-ShareAlike 4.0 International**.

<https://creativecommons.org/licenses/by-sa/4.0/>

In practice, any reuse is permitted, including commercial reuse, on two
conditions: credit the author and the project, and release derivative works
under the same licence.
